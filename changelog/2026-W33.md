## Verification
- Reframes the TDD rule as "Write the test first — yourself," adding a debated section: a Thoughtworks eval found no quality edge for fully agent-internal TDD, at several times the token cost
- New "Mutation testing" rule: plant a known bug and confirm the suite catches it, rather than trusting a red-green cycle the agent both writes and grades
- New "meat proxy" rule: require PR authors to restate the diff in their own words as proof of review, not just a green CI
- New rule: build evals from your own repositories and report task-level win/loss plus steps-to-solution, not a single aggregate pass rate

## Context Engineering
- New rule: lock model and reasoning effort at session start (changing either busts the prompt cache), and set `ENABLE_PROMPT_CACHING_1H=1` on API keys to match the subscription's 1-hour TTL
- New rule: tame noisy command output with quiet flags or subagent delegation — it's resent on every remaining turn, and the 30,000-character spill-to-file threshold misses verbose-but-small output
- New rule: only delegate to a subagent when its output is disposable, since context isolation also means it starts cold and can't reuse the parent's reads
- Checklist gains three items: disable unneeded MCP servers with `/mcp`, `/rename` before `/clear`, export `ENABLE_PROMPT_CACHING_1H=1`

## Team Adoption
- New rule: give channel-resident agents four named response modes (reply inline, open a thread, route to a workstream, stay silent) instead of a single respond/don't-respond classifier, graded partly on whether a human was better suited to answer

## Security and Threat Model
